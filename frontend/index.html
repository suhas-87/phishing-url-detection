🎣 What is Phishing?

Phishing is a cyber attack where adversaries trick victims into revealing sensitive credentials, tokens, or financial details by impersonating trusted entities.

🔗 How Phishing URLs Work

Phishers craft deceptive links using brand typo-squatting, deep nested subdomains, raw IP hosts, and token padding to deceive users and bypass static filters.

🤖 Why Machine Learning?

Static blacklists cannot identify zero-day phishing links created minutes before an attack. Machine Learning models analyze structural features to detect new threats instantly.

📐 Evaluation Metrics

Precision: Measures exactness of phishing alerts.
Recall: Measures proportion of actual threats identified.
F1 Score: Harmonic mean balancing precision and recall.

Extracted Machine Learning Features (11 Features)

url_length: Total character length of URL
domain_length: Character length of hostname
num_dots: Count of '.' in full URL
num_hyphens: Count of '-' (common in typo-squatting)
num_digits: Number of numeric digits
num_special_chars: Count of @, ?, =, _, %, &, +, #
num_slashes: Count of '/' path delimiters
has_https: 1 if HTTPS encrypted, 0 if HTTP
is_ip_address: 1 if host is raw IPv4/IPv6, else 0
num_subdomains: Count of subdomains in domain hierarchy
suspicious_words_count: Matches for login, verify, account, update, secure, bank, signin, confirm

About PhishGuard

Academic Bachelor of Computer Applications (BCA) 3rd-Year Capstone Project

Project Objective

PhishGuard is an intelligent, automated, and real-time cyber defense web application that inspects destination URLs to determine whether they are safe or malicious. The system combines a trained Machine Learning classification pipeline with deep live domain intelligence (DNS, SSL/TLS, WHOIS, IP Geolocation, and Metadata) and safe redirection enforcement.
