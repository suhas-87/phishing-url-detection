🎣 What is Phishing?

Phishing is a cyber attack where attackers trick victims into revealing sensitive credentials, credit card details, or personal data by mimicking trusted institutions (banks, tech providers, social media).

🔗 How Phishing URLs Work

Phishers craft deceptive URLs using brand typo-squatting (e.g. paypal-update.xyz), deep nested subdomains, raw IP hosts, and token padding to deceive users and bypass rudimentary filters.

🤖 Why Machine Learning?

Static blacklists fail against zero-day phishing links created minutes before an attack. Machine Learning models extract structural features and generalize patterns to detect brand-new malicious URLs in milliseconds.

📐 Evaluation Metrics

Precision: Out of all URLs flagged as phishing, how many were truly phishing.
Recall: Out of all real phishing URLs, how many did the model detect.
F1 Score: Harmonic mean balancing precision and recall.

Extracted Machine Learning Features (11 Features)

url_length: Total character length of URL
domain_length: Character length of hostname
num_dots: Count of '.' in full URL
num_hyphens: Count of '-' (common in typo-squatting)
num_digits: Number of numeric digits
num_special_chars: Count of @, ?, =, _, %, &, +, #
num_slashes: Count of '/' path delimiters
has_https: 1 if HTTPS encrypted, 0 if HTTP
is_ip_address: 1 if host is raw IPv4/IPv6, else 0
num_subdomains: Count of subdomains in domain hierarchy
suspicious_words_count: Matches for login, verify, account, update, secure, bank, signin, confirm

About PhishGuard

Academic Bachelor of Computer Applications (BCA) 3rd-Year Capstone Project

Project Objective

The primary objective of PhishGuard is to develop an intelligent, automated, and real-time cyber defense system that analyzes website URLs and predicts whether they are legitimate or malicious phishing links. Unlike traditional static blacklist approaches, this project leverages supervised Machine Learning to inspect structural, lexical, and protocol characteristics of URLs.
